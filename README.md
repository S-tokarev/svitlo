# График света

Приложение показывает статус света по группе в Киевской области: предупреждение за 10 минут до отключения и сообщение, когда свет появился. Виджет на рабочий стол показывает то же самое. Проект для Android лежит в корне, проект для iPhone — в папке `ios`.

График берётся со страницы [vyshgorod.in.ua/svitlo](https://vyshgorod.in.ua/svitlo): там график ДТЕК по группам 1.1–6.2 на сегодня и завтра. Страница проверяется каждые 15 минут. Если расписание выбранной группы изменилось, приходит уведомление. Адрес ищется по справочнику ДТЕК на всю область и выбирает группу.

## Как собрать

Нужны Android Studio и JDK 17.

1. Откройте эту папку в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на телефоне или эмуляторе.

Сборка Android и iPhone запускается в GitHub Actions на каждый push в `main`. Готовые файлы публикуются в [Releases](https://github.com/S-tokarev/svitlo/releases) как «Последняя сборка»: `svitlo-android.apk` и `svitlo-iphonesimulator.zip`. Если телефон пишет, что приложение не установлено, удалите старое «Светло» или «График света» и поставьте APK заново: ранние сборки GitHub подписывались каждый раз новым ключом. Дальше обновления ставятся поверх. Файл для настоящего iPhone (`svitlo-iphone.ipa`) появляется только после подписи Apple. GitHub Packages для этого не используется.

## Windows и Mac

В том же релизе лежат `svitlo-windows.zip`, `svitlo-macos.zip` и `svitlo-macos-intel.zip`. На Mac с процессором Apple (M1 и новее) нужен `svitlo-macos.zip`. На Mac с процессором Intel нужен `svitlo-macos-intel.zip`: другой архив система не откроет. Распакуйте архив и запустите `Svitlo`. В трее есть пункт «Виджет»: небольшое окно поверх остальных показывает статус всех сохранённых адресов. Программа показывает тот же график, группы и поиск адреса. Закрытие окна не выключает её: она остаётся в трее, раз в 15 минут обновляет график и присылает уведомления за 10 минут до отключения, при включении света и при смене расписания. Щелчок по значку в трее снова открывает окно. Повторный запуск открывает уже работающую программу, а не вторую копию. Ночью, с 23:00 до 07:00, уведомления можно отключить галочкой. Чтобы они прекратились, выберите в трее «Выход».

Подпись Apple GitHub сам не выдаёт. Нужен аккаунт [Apple Developer](https://developer.apple.com) и секреты репозитория: `APPLE_TEAM_ID`, `APPLE_CERTIFICATE_P12`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_PROVISIONING_PROFILE`, `APPLE_WIDGET_PROVISIONING_PROFILE`. В профилях должны быть ваш iPhone и App Group `group.ua.in.vyshgorod.svitlo`. Без этого поставить сборку из GitHub на iPhone нельзя. На Mac её можно подписать своим Apple ID прямо в Xcode.

При первом запуске разрешите уведомления. Если телефон агрессивно гасит фон, нажмите «Разрешить работу в фоне» — иначе предупреждение за 10 минут может опоздать. Не смахивайте приложение из списка «принудительно остановить»: после этого Android снимает будильники, пока вы снова не откроете приложение.

## Виджет

Долгое нажатие на рабочий стол → Виджеты → График света. Группа выбирается в приложении. Виджет показывает статус и маленькую шкалу сегодняшнего дня.

## Что делает приложение

- Группу можно выбрать кнопкой или найти по адресу.
- Пока свет есть, видно, во сколько его выключат.
- За 10 минут до отключения приходит уведомление.
- Когда по графику наступает время включения, приходит уведомление.

## iPhone

Откройте `ios/Svitlo.xcodeproj` в Xcode 16 на Mac и выберите свою команду подписи для целей `Svitlo` и `SvitloWidget`. Минимальная система — iOS 17. Собрать и поставить приложение с этого компьютера на Windows нельзя: здесь нет Xcode.

Поведение то же, что на Android: группы 1.1–6.2, адрес по справочнику ДТЕК, график с vyshgorod.in.ua/svitlo, светлая и тёмная тема, тихие часы с 23:00 до 07:00 по Киеву.

iOS не даёт будить приложение ровно каждые 15 минут. График обновляется при открытии, если сохранённой копии больше 15 минут, и через фоновую задачу, которую система может отложить. Уведомления ставятся локально по уже скачанному графику: за 10 минут до отключения и в момент включения.

Виджет читает ту же сохранённую группу через App Group `group.ua.in.vyshgorod.svitlo`. Бесплатная личная команда Apple часто не разрешает App Groups. Тогда подпись цели не соберётся, пока способность не отключена: уберите файл entitlements из подписи обеих целей. Приложение останется рабочим, но виджет не увидит выбранную группу.

Цель `SvitloTests` собирает общую логику отдельно от приложения. На iOS прогон этих тестов может потребовать указать приложение-хост `Svitlo`.
