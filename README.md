# График света

Приложение показывает статус света по группе: предупреждение за 10 минут до отключения и сообщение, когда свет появился. Виджет на рабочий стол показывает то же самое. Проект для Android лежит в корне, проект для iPhone — в папке `ios`. В приложении выбирается область или город Киев. По умолчанию открыта Киевская область.

Для Киевской области график берётся из API ДТЕК: те же группы 1.1–6.2, что на сайте Киевских региональных электросетей. Город Киев и Днепр берутся из открытого API YASNO. Если эти API не отвечают, для области остаётся страница [vyshgorod.in.ua/svitlo](https://vyshgorod.in.ua/svitlo), а для остальных регионов — [alerts.energy](https://alerts.energy). Страница проверяется каждые 15 минут. Если сайт отвечает «слишком много запросов», программа ждёт и оставляет на экране предыдущий график. В настройках можно ввести свой ключ API alerts.energy: тогда запасной график берётся из JSON API, а ключ хранится только на устройстве. Если расписание выбранной группы изменилось, приходит уведомление. Адрес ищется по справочнику ДТЕК только для Киевской области и выбирает группу.

## Как собрать

Нужны Android Studio и JDK 17.

1. Откройте эту папку в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на телефоне или эмуляторе.

GitHub Actions на каждый push в `main` собирает Android, Windows и Mac Intel. Готовые файлы публикуются в [Releases](https://github.com/S-tokarev/svitlo/releases) как «Последняя сборка»: `svitlo-android.apk`, `svitlo-windows.zip` и `svitlo-mac-intel.zip`. Mac с процессором Apple (M1 и новее) и iPhone в Actions не собираются: их собирают локально, как описано ниже. Если телефон пишет, что приложение не установлено, удалите старое «Светло» или «График света» и поставьте APK заново: ранние сборки GitHub подписывались каждый раз новым ключом. Дальше обновления ставятся поверх. GitHub Packages для этого не используется.

## Windows и Mac

В релизе GitHub лежат `svitlo-windows.zip` и `svitlo-mac-intel.zip`. Распакуйте архив и запустите `Svitlo` или `Svitlo.app`. Файл для Mac Intel не откроется на Mac с процессором Apple (M1 и новее).

Mac с процессором Apple собирается на самом компьютере Mac, не в GitHub. В папке проекта выполните `./gradlew :desktop:createDistributable`. Готовое приложение — `desktop/build/compose/binaries/main/app/Svitlo.app`.

В трее есть пункт «Виджет»: небольшое окно поверх остальных показывает статус всех сохранённых адресов. Программа показывает тот же график, выбор области, группы и поиск адреса в Киевской области. Закрытие окна не выключает её: она остаётся в трее, раз в 15 минут обновляет график и присылает уведомления за 10 минут до отключения, при включении света и при смене расписания. Щелчок по значку в трее снова открывает окно. Повторный запуск открывает уже работающую программу, а не вторую копию. Ночью, с 23:00 до 07:00, уведомления можно отключить галочкой. Чтобы они прекратились, выберите в трее «Выход».

При первом запуске разрешите уведомления. Если телефон агрессивно гасит фон, нажмите «Разрешить работу в фоне» — иначе предупреждение за 10 минут может опоздать. Не смахивайте приложение из списка «принудительно остановить»: после этого Android снимает будильники, пока вы снова не откроете приложение.

## Виджет

Долгое нажатие на рабочий стол → Виджеты → График света. Группа выбирается в приложении. Виджет показывает статус и маленькую шкалу сегодняшнего дня.

## Что делает приложение

- Область или Киев выбираются в списке. Группу можно выбрать кнопкой, а в Киевской области ещё найти по адресу.
- Пока свет есть, видно, во сколько его выключат.
- За 10 минут до отключения приходит уведомление.
- Когда по графику наступает время включения, приходит уведомление.

## iPhone

Откройте `ios/Svitlo.xcodeproj` в Xcode 16 на Mac и выберите свою команду подписи для целей `Svitlo` и `SvitloWidget`. Минимальная система — iOS 17. Собрать и поставить приложение с этого компьютера на Windows нельзя: здесь нет Xcode. GitHub Actions iPhone не собирает.

Поведение то же, что на Android: выбор области или Киева, группы выбранного региона, адрес по справочнику ДТЕК в Киевской области, график из API ДТЕК и YASNO, а если они не отвечают — со страниц vyshgorod.in.ua/svitlo и alerts.energy, светлая и тёмная тема, тихие часы с 23:00 до 07:00 по Киеву.

iOS не даёт будить приложение ровно каждые 15 минут. График обновляется при открытии, если сохранённой копии больше 15 минут, и через фоновую задачу, которую система может отложить. Уведомления ставятся локально по уже скачанному графику: за 10 минут до отключения и в момент включения.

Виджет читает ту же сохранённую группу через App Group `group.ua.in.vyshgorod.svitlo`. Бесплатная личная команда Apple часто не разрешает App Groups. Тогда подпись цели не соберётся, пока способность не отключена: уберите файл entitlements из подписи обеих целей. Приложение останется рабочим, но виджет не увидит выбранную группу.

Цель `SvitloTests` собирает общую логику отдельно от приложения. На iOS прогон этих тестов может потребовать указать приложение-хост `Svitlo`.
